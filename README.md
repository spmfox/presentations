Each time a presentation is spoken live, a branch will be created to capture the repo at that time.

## How it works
Presentations are rendered with `marp` and the demos are generated by `vhs`. All reference material like example files, GIFs, and videos are included as well. There are both `.md` and `.html` versions available. The markdown version can be viewed directly here, however the html version will need to be rendered in a browser.

The markdown versions use GIFs and the HTML versions use WebM video.
